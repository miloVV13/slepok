# Ручная приёмка RP2040 на macOS

**Статус: отложена, не проводилась.** На 2026-10-31 у пользователя
нет Mac под рукой. Выполнить при появлении машины; нативный CI
сборки/восстановления пройден отдельно, без отключения сети.

Текущая матрица CI: macOS 15, Apple Silicon (`macos-arm64`) и Intel
(`macos-x64`). Более старые версии ОС не заявлены; Intel runtime zstd
взят из бутылки для macOS 15. Для `init` нужен Git и доступ к сети.
Получателю нужны только бинарник Slepok для его CPU и архив.
Homebrew, SDK и компилятор устанавливать не нужно.

## Отправитель

Положите соответствующий бинарник под именем `slepok` в отдельный
каталог и откройте Terminal в этом каталоге. Если при переносе потерялся
Unix-признак исполнения, восстановите его `chmod +x ./slepok`.
Обычная подготовка слепка только для текущего Mac:

```sh
./slepok version
./slepok init blink
cd blink
../slepok build
shasum -a 256 build/*.uf2
../slepok pack -o ../blink.slepok
cd ..
./slepok validate blink.slepok
./slepok inspect blink.slepok
shasum -a 256 blink.slepok
```

Сохраните вывод и UF2. Не меняйте исходники и lock между проверками.

## Чистый получатель

Используйте новую VM или пользователя с пустым хранилищем. Отключите
сетевой адаптер до проверки и распаковки; перенесите `slepok` и архив
через диск/USB. Из каталога с ними:

```sh
./slepok validate blink.slepok
./slepok unpack blink.slepok restored
cd restored
../slepok build
shasum -a 256 build/*.uf2
test -s build/compile_commands.json && echo 'compile_commands: OK'
```

Ожидается успешная сборка без сети. UF2 на той же архитектуре Mac
должен совпасть с отправителем. База компиляции должна ссылаться на
хранилище получателя, без путей отправителя.

`SLEPOK_HOME` не задавайте: по умолчанию используется
`~/Library/Application Support/slepok`. Путь с пробелами нормален.
Предупреждение об отсутствии сетевой изоляции ожидаемо; отключение
сети выполняется на уровне машины, а не внутри Slepok.

## Две архитектуры и другие ОС

На отправителе можно подготовить обе архитектуры без Rosetta:

```sh
./slepok init --platform macos-arm64,macos-x64 dual-blink
cd dual-blink
../slepok pack --platform macos-arm64,macos-x64 -o ../mac-dual.slepok
```

Чужие Unix-пакеты сохраняются tar-архивами без запуска. Получатель
выбирает свои инструменты. Тот же сценарий работает для общего
слепка с Linux и Windows:

```sh
../slepok init --platform linux-x64,windows-x64,macos-arm64,macos-x64
../slepok pack --platform linux-x64,windows-x64,macos-arm64,macos-x64 -o ../all-hosts.slepok
```

Проверочная сборка `pack` выполняется только на ОС отправителя.
Каждую платформу затем проверьте нативно. Совпадение UF2 между разными
архитектурами/ОС пока отдельно не обещается; сравнивайте один и тот же
слепок до/после переноса на одинаковой хостовой платформе.

Проверки Windows/Linux описаны в [общей инструкции](NATIVE_ACCEPTANCE.md).
Для каждой независимой приёмки используйте пустое хранилище получателя.

## Дополнительные проверки

- Повторите распаковку в каталог с пробелами.
- Прервите первую сборку Ctrl+C: ожидается код `130` и остановка
  дочерних компиляторов; повторный `build` должен завершиться.
- Проверьте `slepok shell`, `cmake --version` и сборку через CMake.
- Отдельно зафиксируйте поведение при скачивании бинарника браузером
  и проверке Gatekeeper/quarantine; настройки безопасности системы
  специально менять не нужно.
- При ошибке сохраните точную команду, вывод, код `echo $?`, путь к
  логу, `slepok.toml`, `slepok.lock` и версию macOS/CPU.
